## Exact scope

Every skill contributes at least ten distinct usable canonical tasks: 4 core, 3 support, 3 stretch. Starter tasks count only if genuine objective/band demand matches; cosmetic/name/option-order changes and retries do not meet the floor. Deterministic generator domains can exceed it. Each record has one primary assessed objective, exact official source/programme section, authored demand rationale, response spec, all legitimate control answers, explanation, two non-answer-revealing hints and separate assisted worked support. Only reviewed/validated records can ship.

Support/core/stretch express actual objective/representation/reasoning demand, not larger numbers, speed, multiplier or uniform ability across subjects. Support can revisit introductory demand; core is Year 4-centred; stretch uses justified selected Year 5/English 5–6 demand or genuinely less direct/additional reasoning. No hard age/quest lock, full-curriculum claim, arbitrary free-text grade or runtime LLM. Records distinguish instruction/assessed-text and contextual non-assessed skills; content supports safe narration/help without producing audio. Choices, ordered tile IDs, group/pair maps and bounded quantities are responses; DOM coordinates/text are not.

Preserve starter canonical identity and meaningful family/equivalence parameters independently of seeds/order/skins/releases/week/answer. New equivalence versions require reviewed substantive task changes and receipt compatibility. Content errors return unavailable-content; malformed/incomplete inputs remain unscored, complete wrong answers judged. Wrong answers supply only justified observations, not diagnosis. Optional quest revisits can carry breadth; no extra quests or compulsory full-bank completion.
