## Produced outputs/interfaces

**Native draft/input contract.** WP03 produces TaskDefinition/ActivityResponse, not a state-bearing TaskView. WP02-06A's local activity adapter combines that definition with WP04's committed encounter. Widgets receive only the definition's response specification/options/ranges and an ActivityDraft; they have no need for reward/encounter IDs, answer rules or hint bodies. ActivityDraft contains the response discriminant and current values plus transient selection/drag/undo information. reduceDraft handles select/place/remove/move/set/increment/undo identically for pointer/tap/keyboard; toResponse strips UI state into WP03's ActivityResponse without judging correctness. Reusable planks have transient instance IDs, never new reward identities.

Signatures: `createDraft(responseSpec, savedResponse?) -> ActivityDraft`; `reduceDraft(draft, action, responseSpec) -> ActivityDraft`; `toResponse(draft) -> ActivityResponse`. All are pure. `ActivityWidgetProps = { responseSpec, draft, disabled, onAction(action): void }`; disabled means a consuming commit is pending, not that an answer is wrong. Bridge stores an ordered instance list with integer lengths; punctuation maps stable slot IDs to mark or empty; merchant stores integer apple/pear counts or empty. Native controls enforce declared shape/ranges only; WP03 distinguishes incomplete, invalid and judged responses. Undo is session-local and never rewinds a committed Check/help record. Widgets cannot emit Check, award, speech or storage events.

`bindPointerDrag(element, { getDraft, resolveDropTarget, onAction }) -> dispose` installs one gesture owner; `cancelDrag()` only removes the ghost/selection. `resolveDropTarget(clientPoint, currentTargets) -> targetId|null` uses current viewport rectangles. Completed drops emit the same DraftAction as buttons; moving/invalid drops emit none. Route rotation/teardown disposes listeners and releases capture; no external drag library or document-global mutable draft is needed.

Capture one pointer, draw a transient ghost and resolve drop targets from current viewport geometry because capture changes the event target. Pointercancel/lost capture/Escape/rotation/route teardown cancel the drag without scoring or corrupting the last completed edit. Suppress touch-action only on drag handles; preserve ordinary scrolling. Labelled native buttons provide tap-select/place and keyboard Enter/Space plus remove/increment/move-before/after. Restore focus after overlays and announce concise edits/feedback, not every pointermove. CSS handles ambient decoration; cancellable Web Animations handles restoration. System reduced motion OR profile quiet preference cancels live decorative movement/travel and shows correct static state; animation completion never authorizes progression.

## Acceptance criteria

1. Bridge planks, punctuation tiles and fruit add/remove produce identical domain response through pointer, tap-select/place and keyboard.
2. Selection/remove/rearrange/undo/tentative totals preserve construction without judging/scoring.
3. Pointercancel/lost capture/Escape/rotation/route teardown cannot score or commit half-drag; handles alone block scroll.
4. Comfortable targets/focus/text remain reachable after rotation/200% text.
5. This M1 widget handoff covers its three mechanics; WP02-09A later supplies the remaining three. WP02-13A reports supporting six-mechanic evidence to WP06-07A, without holding this child open until M2.

6. For each starter response form, demonstrate create→edit→undo→remove through all supported routes and compare serialized responses. Respect WP03's legal ranges/slot completeness without duplicating its correctness judgement; incomplete structural input remains distinct from a mathematically wrong complete answer.
7. Complete an ordinary page scroll outside drag handles, cancel one active drag by rotation/lost capture, and return focus after an overlay. The last completed construction survives, one pointer cannot be confused with another, and no Check/help/reward event is emitted by those operations.
