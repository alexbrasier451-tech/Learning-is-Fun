## Produced outputs/interfaces

`HallOfChampions({ model: LeaderboardReadModel, refreshStatus, onRefresh, onOpenHistory, onClose })` and `PersonalHistory({ profileId, model, onBack })` are controlled components with no repository/clock imports. WP04/WP01 adapters derive the model from committed state using WP05-03A, dispatch calendar refresh on entry and pass pending/failure/stale status separately from scores. Switching the selected profile chooses `personalRecordsByProfile[profileId]`; it never recalculates medals from the retained archive window. Current ranks are labelled provisional; closed medals and personal totals remain separately labelled. Repeated mounts/refresh calls cannot award in the UI. Surface the actual London Monday date range and local-browser scope; do not display current-week rank as a finalized trophy.

Use the existing storybook palette/type/illustrated frame and avatar references from early WP02 assets, with native accessible table/list semantics, readable labels and focusable history/back controls. No placeholder rivals, emoji production portraits, marketing statistics or dense administrative dashboard. Render local no-profile, unscored, single-profile, positive tie, cap reached, omitted historical entry and refresh-failure states from the finite supplied read-model fixtures. Preserve last committed rows during refresh failures and visibly label their freshness.

HallOfChampions and PersonalHistory consume committed LeaderboardReadModel only: browser-local label, London current-week label/clock notice, nickname/avatar, competitive/lifetime points, used slots/30, rank or not-yet-scored, recent closed results, personal best and cumulative medals. Opening board requests WP04 calendar refresh. Accessible loading/failure/stale state never masquerades as new closed results. Separate provisional current board from immutable history; show 52-participating-week display retention and deleted-entry omission. One player sees actual self/history; none has honest empty state. Cosmetic earning feedback references permanent choices without score spending.
