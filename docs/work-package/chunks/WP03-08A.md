Supply independent answers and Q4/Q8/Q9/Q10 bindings to WP03-13A; do not produce SVG art, a chart engine or competition-calendar code.

Export `TIME_SPACE_DATA_TASKS: readonly TaskDefinition[]`, `TIME_SPACE_DATA_MANIFEST: TaskFamilyManifest`, `evaluateExpansionTimeSpaceData(task, response): EvaluationResult` and `validateTimeSpaceDataTask(task): readonly ContentIssue[]`. Enumerate fixed task tuples. Clock input uses integer minutes 0–1439; day offsets are explicit 0/1 and durations bounded 0–1440 minutes. Timetables have at most six labelled rows; sequences at most five distinct tile IDs. Geometry uses named reviewed shape properties and clockwise/anticlockwise quarter/half/full turns expressed by choice IDs, not pointer angles. Chart/table datasets have at most six labelled categories/points, integer values 0–100 and an explicit integer scale; a line graph has an ordered labelled horizontal domain. Choice answers have at most four alternatives; numeric chart/duration answers use quantity slots with declared units. Data/text alternatives repeat source labels/values, not derived answers. WP02's existing selection/manipulation widgets consume this metadata; no specialist graph/geometry library is introduced.

Author `TaskDefinition.stimulus` using only the clock/diagram/data variants in [WP03-01A](WP03-01A.md); [WP02-09A](WP02-09A.md) renders them. Set clock face and display convention explicitly; minutes/dayOffset describe the source clock, while the learner's clock response is separate integer minutes. An analogue-reading alternative describes given hand positions/period, not the time being requested. Diagrams have explicit point/edge identities and labels; verify closed boundaries and equal coordinate scale, and never score a pointer coordinate. Geometry alternatives describe the source arrangement without naming the property/shape being assessed. Data uses the authored order, axis labels, unit, positive scaleStep and exact rows; line positions are equally spaced labelled periods. Alternatives reproduce source values but do not add the requested comparison, total or inference. Use absent/null for text-only tasks. Validate each real stimulus with its prompt and reviewed answer, then reference its source/alternative pair from the family manifest sent to WP03-13A.

## Exact scope

Every skill contributes at least ten distinct usable canonical tasks: 4 core, 3 support, 3 stretch. Starter tasks count only if genuine objective/band demand matches; cosmetic/name/option-order changes and retries do not meet the floor. Deterministic generator domains can exceed it. Each record has one primary assessed objective, exact official source/programme section, authored demand rationale, response spec, all legitimate control answers, explanation, two non-answer-revealing hints and separate assisted worked support. Only reviewed/validated records can ship.

Support/core/stretch express actual objective/representation/reasoning demand, not larger numbers, speed, multiplier or uniform ability across subjects. Support can revisit introductory demand; core is Year 4-centred; stretch uses justified selected Year 5/English 5–6 demand or genuinely less direct/additional reasoning. No hard age/quest lock, full-curriculum claim, arbitrary free-text grade or runtime LLM. Records distinguish instruction/assessed-text and contextual non-assessed skills; content supports safe narration/help without producing audio. Choices, ordered tile IDs, group/pair maps and bounded quantities are responses; DOM coordinates/text are not.

Preserve starter canonical identity and meaningful family/equivalence parameters independently of seeds/order/skins/releases/week/answer. New equivalence versions require reviewed substantive task changes and receipt compatibility. Content errors return unavailable-content; malformed/incomplete inputs remain unscored, complete wrong answers judged. Wrong answers supply only justified observations, not diagnosis. Optional quest revisits can carry breadth; no extra quests or compulsory full-bank completion.
