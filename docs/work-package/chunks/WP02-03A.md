## Target outcome

**Music and sound from the first slice.** Deliver two original, seamless background loops of roughly 60–90 seconds: a gentle outdoor/village theme for the green, bridge and market, and a quieter related library theme. Use the same small palette of soft plucked/bell-like tones, warm sustained tones and restrained wooden percussion; no lyrics, harsh failure buzzer or incessant fanfare. These are arranged musical phrases with variation and space, not a single repeated beep. Add five short effects: pickup, placement, supportive feedback, success and restoration; the final restoration cue also serves the welcome scene. Expansion reuses these themes/palette for all seven locations; further tracks are not required. Speech lowers background music while active and stopping it restores only the previously permitted level. Source amplitude and mix must avoid clipping, startling level jumps and masking instructions; acoustic quality requires listening, not event logs alone.

## Produced outputs/interfaces

**Audio production handoff/formats.** Original composition JSON records tempo, instruments/envelopes, note/duration/level events, sample rate/frame count and loop points; retain renderer/masters and optional AUP3 mixes or original raw recordings/creator permission. Runtime exports: village-loop.wav and library-loop.wav (60–90 seconds each), pickup.wav, placement.wav, support.wav, success.wav, restoration.wav. Use mono 44.1kHz 16-bit PCM WAV, decoded Web Audio buffers with explicit loopStart/loopEnd; not repeated HTML-media ended events. Phrase-aligned looping with folded reverb tails avoids codec padding uncertainty; do not insert silence at joins. Reserve mix headroom and listen to two joins/every cue at default levels and alongside speech; peak checks alone do not prove comfort.

Two maximum-length PCM loops total about 15.9MB before effects; decoded mono float buffers at 48kHz use about 34.6MB for the pair. These are WP01 sizing inputs, not accepted performance budgets. Decode lazily, retain current/briefly incoming theme, release superseded buffers; propose four effect voices with oldest transient replaced. If measured cache/device limits require compression, choose an evidenced supported format and recheck loop joins on D1–T2; no unverified gapless MP3 claim. No streaming, runtime MIDI/SoundFont/synth scheduler or editor dependency.

Asset-register entries link ID, editable source/runtime paths, author/source URL, exact original permission or third-party licence/version/link, modifications/attribution, dimensions or audio rate/duration/loop frames and byte count. Preserve downloaded licence evidence on reuse. Do not arbitrarily relicense original project art as CC0/GPL. Readable credits consume this register; WP01 caches every required runtime file under its base path, not editable sources. No paid service, trial or account is required.

`AUDIO_ASSETS` is a readonly record keyed by `village`, `library`, `pickup`, `placement`, `support`, `success`, `restoration`. Entries supply `{ assetId, path, kind: 'loop'|'effect', sampleRate, frameCount, bytes, loopStartFrame?, loopEndFrame? }`; loop end is exclusive, seconds are frames/sampleRate. Paths are `assets/audio/<filename>` through WP01's base resolver. The catalogue imports no controller/state module. WP02-05A consumes it; WP01 receives the same seven runtime paths and measured largest/total bytes through the register, not a divergent second inventory.

Sources are `assets/source/audio/village.json`, `library.json`, `effects.json`; `tools/render-audio.mjs` reads those explicit inputs and writes only the seven named WAVs. Original notes/envelopes and fixed synthesis-noise seeds produce repeatable offline exports. Keep metadata/listening findings in docs/audio-direction.md. Optional recorded replacements retain originals and permission in the same source tree. Source checks do not start/persist game audio preferences.

## Acceptance criteria

1. Deliver exactly two related 60–90-second loop exports and the five named cues. Each theme contains arranged phrases, variation and space with the shared soft palette; no lyrics, harsh failure buzzer, placeholder repeated beep or extra soundtrack requirement.
2. All seven runtime files are valid mono 44.1 kHz 16-bit PCM WAV; decoded duration, frame count, loop start/end and measured bytes agree with the catalogue. The loop span is nonempty and within the decoded buffer; phrase/tail treatment has no intentionally inserted join silence.
3. Actually listen through two joins per theme and every cue at the proposed relative mix levels. Record no unintended clicks/gaps/clipping or startling relative jumps, with corrections where needed. Numeric peaks alone cannot pass acoustic quality. If no listening route exists, deliver technical evidence with acoustic status unverified and a named audio-capable review handoff; never claim this quality criterion passed.
4. Editable compositions/renderer or original-recording sources reproduce the exports without a paid service/trial/account. Rights/attribution cover every reused sample and export; do not infer sample rights from editor licences.
5. Runtime theme changes, speech masking, simultaneous sources and mute behaviour remain WP02-05A integration and published WP06/WP02-12A checks. This source-production handoff does not wait for those downstream components; required acoustic uncertainty remains visible in release evidence.
