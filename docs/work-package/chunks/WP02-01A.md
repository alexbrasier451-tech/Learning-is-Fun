## Target outcome

**Direction and visual identity.** Retain *The Lost Kingdom* as a working adventure title under *Learning is Fun*. Use a layered storybook miniature: illustrated 2D scenes with shallow depth, soft cast shadows, warm paper surfaces, rounded expressive characters and crisp manipulable objects. Palette roles are cream for reading surfaces, deep ink for text, forest/teal for the world, amber for interactable accents and muted coral/plum for supporting colour. State also uses shape, label and motion, never colour alone. Each location has a distinctive landmark and restrained foreground/middle/background layers. UI stays readable on quiet panels; puzzle text is live text, not baked into scenery. Avoid mixed stock-art styles, emoji as production characters, glossy generic dashboard cards and large empty canvases. Final colour values and fonts follow assessment and contrast checks; use a readable system sans-serif baseline with no required font service.

**Shared interaction/accessibility target.** Each drag action has a tap/click-select then tap/click-place alternative and a keyboard equivalent. Matching selects two items; sequencing has move-before/after controls; sorting selects item/category; manipulation offers increment/decrement or equivalent labelled controls; selection exposes focusable choices. Keyboard-only completion, visible focus, no focus trap, return focus after overlays and an Escape/back route are required. A keyboard alternative alone is not a touchscreen drag alternative, as explained by [W3C Dragging Movements](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html).

Aim for at least 44×44 CSS-pixel hit areas for game controls and selectable objects, with no overlapping targets; small punctuation glyphs sit in larger tiles. This adopts the stronger target size from [W3C Target Size Enhanced](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced), not an assertion that 44 pixels is the AA minimum. Use at least 18 CSS-pixel default child-facing prompt/body text and 16 for secondary labels; allow 200% text enlargement without losing instructions or actions. Use 4.5:1 minimum normal-text contrast and 3:1 for qualifying large text ([W3C Contrast Minimum](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html)); give active controls and focus a clearly distinguishable boundary. Text, shape and labelled feedback supplement colour. These are bounded product targets, not a full WCAG conformance claim.

No hover-only instructions, precision timing, required multi-touch or orientation lock. Changing orientation preserves tentative answers and reveals all controls. A quieter-motion setting (including system preference) suppresses decorative loops, camera travel and particle bursts while retaining immediate static state changes. Instructions have user-triggered read-aloud where supported, with visible equivalent text, stop/replay and graceful unavailable-voice handling. Do not automatically read assessed passages or punctuation answers; WP03 records assistance when passage read-aloud is offered. Speech is optional: all quests remain completable without it. DEC-020 restricts the runtime to English localService voices, with text fallback when absent; WP01 verifies the actual local-data behaviour rather than assuming every voice is local.

**Early completion target.** Freeze exactly seven scene IDs, Q1–Q10 and their prerequisite/restoration facts, M1/M2 availability and DEC-021 cosmetic associations before state contracts. Choose concrete readable palette/type/control tokens and one compact reference; describe future M2 assets by stable references without requiring their files to exist. This static catalogue is available to reducers and validators without a renderer, facade or final shell.
