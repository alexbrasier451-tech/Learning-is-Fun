## Acceptance criteria

1. **Findings and closure:** every defect identifies environment/build, reproduction, expected/actual behaviour, evidence and accountable causal lane. Open defects that prevent a required journey/control, give wrong accepted-answer/scoring behaviour, lose/misattribute saves, or fail a required visual criterion block acceptance. Minor observations outside required criteria can remain with owner, impact and disposition. A failed required case cannot be waived into “passed” by this worker; scope changes go to the Controller.

2. **Retest:** after each fix, repeat the original failing journey end to end against the newly published build, plus relevant nearby variants. Refresh final D1/T1 completion evidence if a change affects their integrated path; rerun affected matrix cells and existing relevant regressions. Every required row has a passing record applicable to the final build, either rerun or explicitly retained with an unchanged-scope rationale. Do not repeat unrelated broad suites merely because a cosmetic observation changed.

3. Every required journey/access/local/calendar/offline/visual/audio row has an applicable result; absent mode is blocked/untested rather than inferred. Acoustic evidence is separately verified and same-build/assets applicable, or overall audio acceptance is pending.
4. A release result distinguishes published successful build from accepted game. M1 only can be accepted now; broader ten-quest acceptance awaits WP06-05A/06A.
5. Retain ordinary minor observations with owner/impact/disposition; required criteria cannot be waived by this worker. Scope/interface changes return to Controller.
6. The final report names one frozen M1 candidate and reconciles every D1–T2 journey row, controlled boundary row and WP02-12A criterion disposition. Confirm actual agent-chosen D1/T1 actions, both tracks/two loop joins each/all five cues, and remembered independent mute/volume/Silence all/Stop evidence. Any mandatory acoustic gap prevents full acceptance; a technical pass cannot overwrite it. Only this child declares the M1 gate, with no M2 evidence prerequisite.
