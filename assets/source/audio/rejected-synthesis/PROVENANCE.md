# Original soundtrack provenance

Produced 9 October 2026 for Learning is Fun / The Lost Kingdom, under the human's
explicit instruction to produce original music/effects using free tools and the
Controller's WP02-03A source-production assignment.

Author: OpenAI Codex, original score and offline synthesis for the project requester.
Project-use holder: the Learning is Fun project requester, for this commissioned
AI-generated output. This records the intended recipient and authorized project
use, including editing and distributing these sources/exports in the project.
It does not assert human authorship, copyright eligibility, exclusivity or a
new third-party copyright grant. No CC0, GPL or other open-content dedication
has been invented. No external attribution obligation is introduced.

All note arrangements, envelopes, oscillator partials, reflection taps and fixed
noise seeds were authored in this task. No existing song, third-party sample,
recording, SoundFont, stock asset, remote instrument or music-generation service
was used. The project brief supplied the soft sonic palette and finite inventory;
there is no external sonic reference or reused tune. The original F#–A–B / A–E
motif is shared between the village, library and restoration cue.

Editable masters are village.json, library.json and effects.json. These contain
the actual events, durations in beats, MIDI pitches, linear levels, instrument
definitions, sample/frame counts, loop points and reflection settings. The local
tools/render-audio.mjs renderer produces the seven WAV masters/runtime exports
without an intermediate lossy format. Runtime files contain PCM, not synthesizer
code. verify-audio.mjs builds an explicitly non-runtime review derivative from
those exact WAV samples; its timeline documents cuts, gains and outer fades.

Tool actually used: existing bundled Node.js v24.19.0 with built-in filesystem,
math, buffers and SHA-256; existing TypeScript checks the data-only catalogue.
No paid dependency, additional account, trial, download or editor installation
was required. Node/tool licences are not licences to third-party music; no such
music was imported. Provenance is an authorship/process record, not legal advice.

listening result. Acoustic acceptance is UNVERIFIED; see docs/audio-direction.md
