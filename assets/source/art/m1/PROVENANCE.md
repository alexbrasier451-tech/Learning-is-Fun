# Original M1 artwork provenance

Produced on 9 October 2026 for the Learning is Fun project, under the explicit
WP02-02A instruction to create original finished artwork using free tools.

Author: OpenAI Codex, original text-authored vector artwork for the project requester.
Project-use holder: the Learning is Fun project requester, for this commissioned
AI-generated output. This records the intended recipient and authorized project
use; it does not assert human authorship, copyright eligibility, exclusivity, or
a new third-party copyright grant.

All shapes, compositions, gradients and illustrated characters in these 36
exports were authored in this task. No stock pack, traced external artwork,
remote image, font, paid service, account, trial, or media-generation service
was used. The project-owned `docs/art-direction.md`, its compact reference SVG,
and the frozen experience catalogue supplied palette, cast and inventory direction.
The implementation retains editable SVG plus `build-art.mjs`, which constructs
the geometry with original literal paths and deterministic repetition.

The original-source and runtime SVG pairs are byte-identical. `manifest.json`
records the measured dimensions, byte lengths, SHA-256, exact mapping and all
internal IDs. Runtime assets contain only local vector markup. Each SVG is
stored on one line without a terminal newline so automatic checkout
line-ending conversion cannot invalidate the measured byte counts. Editable
layers are retained; the formatted JavaScript authoring source is retained too.
Every internal ID starts with its export ID. Browser-native gradients are used; no editor or
third-party artwork licence is transferred to this output. No CC0, GPL or other
open-content dedication has been invented. Project credits may use the author
field; there is no external attribution obligation introduced by these assets.

Tools actually used: bundled Node.js (version recorded in manifest), the existing
project React 19.3.0 / Vite 8.3.4 development fixture, TypeScript 7.0.2, Playwright
1.64.0 and its Chromium 156.0.8078.4 renderer. These software packages are authoring
and inspection tools, not sources of artwork. No Inkscape/Krita binary was needed
or installed. Existing dependency licences remain in their packages.

Visual review: scene states and all asset families were inspected in the browser
at 1366×768, 1024×768 and 768×1024. See `evidence/`, `browser-checks.json` there,
and the WP02-02A execution handoff for corrections and evidence limits. The
retained `early-*` images are explicitly superseded draft evidence. Final exported
art has no animation dependency; restored and static decoded pixels match.
